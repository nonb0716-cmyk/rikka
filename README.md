# 六花 (Rikka) — 高機能ライトノベルエディター

長編小説・Web小説の執筆に特化した、ローカル完結型のWebブラウザエディターです。
100万字超の大規模な長編でも軽快に動作し、物語の設定やキャラクター管理を執筆とシームレスに連携できます。

- **公式サイト（試用版・詳細）**: https://rikka-novel.com/
- **製品版のご購入・解説（note）**: https://note.com/nonb0716/n/n284b844f8bac

## 主な特徴
- **長編特化の快適動作**: 数百話・100万字超の構成でもストレスなく書ける軽量設計
- **人物台帳・設定資料の連動**: キャラクター設定（画像含む）や世界観設定を執筆画面と横断管理
- **主要Web小説サイトへの変換出力**: 「小説家になろう」「カクヨム」等に応じたルビ・改行の整形機能
- **安心の完全ローカル動作**: 原稿や設定データは外部サーバーに一切送信されず、手元のブラウザ内のみで安全に保持
